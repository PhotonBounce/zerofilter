# ZeroFilter (zerofilter.news)

> **Unfiltered Geopolitics, Quantum Reality & Frontier Science — Zero Partisan Bullshit.**

An hourly, 3-minute uncensored intelligence broadcast portal cutting through partisan theater, theocratic extremism, authoritarian propaganda, and corporate corruption — synthesized with cutting-edge quantum physics, AI breakthroughs, and declassified consciousness science.

---

## ⚡ What is ZeroFilter?

* **Format:** Exactly 3 minutes (180 seconds) every hour. Rapid-fire, dense, high-impact news curation with zero fluff.
* **Host Persona:** **Rex Vance** — an uncompromising, razor-sharp, foul-mouthed truth-teller who holds zero sacred cows. Hates MAGA authoritarianism, hates corrupt corporate Democrats, defends Ukraine and free democracies, exposes theocratic subversion without apology, and breaks down quantum delayed-choice experiments and declassified CIA remote viewing like a lucid genius.
* **Content Split (Per 3-Minute Release):**
  1. **Minute 1 (0:00–1:00):** Geopolitics & Political Corruption (50% US vs. 50% Global / Ukraine / Anti-Theocracy / Anti-Partisan).
  2. **Minute 2 (1:00–2:00):** Frontier Hard Science (AI, Quantum Mechanics, Half-Mirrored Delayed Choice, Genetic Engineering).
  3. **Minute 3 (2:00–3:00):** Consciousness & Esoteric Frontiers (Project Stargate Remote Viewing, PEAR Lab, Thomas Campbell's My Big TOE, Robert Monroe's Gateway, Simulation Theory).
* **Tech Stack:** Zero-dependency Vanilla HTML5, Vanilla CSS, Vanilla ES Modules, synchronized audio/video player, 10s looping video covers, and real-time story art overlays.

## 🚀 Quickstart

### Launch Web Portal
```bash
npx serve web -l 4200
```
Then visit `http://localhost:4200` in any modern browser.

### Run Engine Tests
```bash
cd engine
node unit.mjs
```
